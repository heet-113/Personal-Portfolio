# Personal Portfolio

This is a personal portfolio website for Heet Rupapara. It presents a clean single-page layout with a hero section, an about section, featured projects, and contact links.

## Live Demo

Visit the deployed site here:

[Live Demo](https://heet-113.github.io/Personal-Portfolio/)

## Features

- Responsive one-page portfolio layout
- Hero section with profile image and social links
- About section with background and skills
- Projects section with source and live demo links
- Smooth scrolling, reveal animations, and mobile navigation

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` - Main portfolio markup
- `style.css` - Site styling and responsive layout
- `script.js` - Navigation, scrolling, and reveal interactions
- `assets/` - Images and media used by the site
